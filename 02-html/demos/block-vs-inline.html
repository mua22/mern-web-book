📦 Block vs Inline Tags

Understanding HTML Element Display Types

Block Elements

Block elements take up the full width available and always start on a new line. They stack vertically on top of each other.

📋 Common Block Elements

Common block-level HTML tags:

  • <div> - Generic container
  • <p> - Paragraph
  • <h1> to <h6> - Headings
  • <section> - Semantic section
  • <article> - Article content
  • <header> - Header section
  • <footer> - Footer section
  • <ul>, <ol> - Lists

Inline Elements

Inline elements only take up as much width as necessary and do not start on a new line. They flow within text.

📋 Common Inline Elements

Common inline HTML tags:

  • <span> - Generic inline container
  • <a> - Hyperlink
  • <strong> - Strong emphasis (bold)
  • <em> - Emphasis (italic)
  • <img> - Image
  • <button> - Button (inline-block)
  • <b> - Bold text
  • <i> - Italic text

Comparison Table

Feature BLOCK INLINE
Width Takes full available width Only uses necessary width
Line Break Starts and ends with new line No line breaks
Margin/Padding All sides work (top, bottom, left, right) Left and right only (top/bottom ignored)
Height/Width Can be set with CSS Cannot be set (ignored)
Vertical Align Not applicable Can be aligned vertically with text
Examples div, p, h1-h6, section, article span, a, strong, em, button

Bonus: Inline-Block Elements

Inline-block elements combine properties of both block and inline elements. They flow inline but can have width, height, and all margin/padding properties.

🎯 Key Takeaways

BLOCK

  • Full width containers
  • New line before and after
  • All margin/padding work
  • Use for layout sections

INLINE

  • Minimal width needed
  • Flow within text
  • Only left/right margins
  • Use for text styling

💡 Tip: Use CSS display: block;, display: inline;, or display: inline-block; to change element behavior

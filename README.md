# Web Dev Book — CSC336 & CSC337

An online, lecture-by-lecture textbook for two COMSATS courses:

- **Web Technologies (CSC336)** — 32 lectures, beginner-friendly, for 5th-semester CS students.
- **Advanced Web Technologies (CSC337)** — 32 lectures, production/enterprise-level, for
  students who've completed CSC336.

Built with [MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/),
generated from the official course lecture-wise plans in [`course-cdf/`](course-cdf).

## Project structure

```
course-cdf/                          Source-of-truth course documents (CDF + lecture-wise plan .doc/.docx)
data/                                Extracted lecture-topic JSON (generated by the skills below)
docs/                                MkDocs content root
  index.md                           Book landing page
  tags.md                            Auto-generated tag index
  web-technologies/                  CSC336 — index.md + lecture-01 .. lecture-32
  advanced-web-technologies/         CSC337 — index.md + lecture-01 .. lecture-32
  stylesheets/extra.css              Theme customizations (hero, course cards, tables)
  assets/logo.svg                    Site logo / favicon
.claude/skills/
  list-web-technologies-topics/      Skill: extract CSC336's lecture-wise topics
  list-advanced-web-technologies-topics/  Skill: extract CSC337's lecture-wise topics
mkdocs.yml                           Site config: theme, navigation, markdown extensions
requirements.txt                     Python deps (mkdocs-material, plugins)
package.json                         npm scripts wrapping the Python/MkDocs toolchain
```

## Navigation

The site's top nav has two tabs, one per course. Within each course, lectures are grouped
into the **7 units** defined in the official Course Description Form (CDF), so the sidebar
mirrors how the course is actually taught.

## Getting started

```bash
npm run setup       # pip install -r requirements.txt
npm run docs:dev    # mkdocs serve — live-reloading local preview
```

## npm scripts

| Script | What it does |
|---|---|
| `npm run setup` | Installs the Python/MkDocs dependencies |
| `npm run docs:dev` | Serves the site locally with live reload (`mkdocs serve`) |
| `npm run docs:dev:host` | Same, but bound to `0.0.0.0` so it's reachable on your LAN |
| `npm start` | Alias for `docs:dev` |
| `npm run docs:build` | Production build with `--strict` (fails on broken links/nav) |
| `npm run docs:build:clean` | Removes `site/` first, then builds |
| `npm run docs:deploy` | Publishes `site/` to the `gh-pages` branch (`mkdocs gh-deploy`) |
| `npm run docs:clean` | Removes the built `site/` directory |
| `npm run topics:web-technologies` | Runs the CSC336 topic-extraction skill and prints the lecture-wise outline |
| `npm run topics:advanced-web-technologies` | Same, for CSC337 |
| `npm run topics:all` | Runs both |

## Regenerating content from the course plans

If `course-cdf/*.doc` changes (a new lecture-wise plan is issued):

1. Re-run the relevant skill to get the updated topic list:
   ```bash
   npm run topics:web-technologies -- --json data/csc336_topics.json
   npm run topics:advanced-web-technologies -- --json data/csc337_topics.json
   ```
2. Diff the JSON against the previous version to see what changed.
3. Update the affected chapter(s) under `docs/web-technologies/` or
   `docs/advanced-web-technologies/`, and update the `nav:` entry in `mkdocs.yml` if a
   lecture was added, removed, or retitled.
4. `npm run docs:build` (strict mode) to confirm nothing is broken before deploying.

## Requirements

- Python 3.9+ with `pip`
- [`antiword`](https://github.com/grobian/antiword) on `PATH` (used by the topic-extraction
  skills to read the legacy `.doc` lecture-wise plan files)
- Node.js (only needed to run the npm script wrappers — the site itself has no JS runtime
  dependency)

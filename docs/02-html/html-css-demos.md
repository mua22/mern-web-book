# HTML/CSS Demos
This page contains practical **HTML and CSS demonstrations** designed to help you understand how web pages are structured and styled. The goal of these demos is to move beyond theory and show how individual concepts work together to create real, usable web interfaces.

HTML demos focus on **page structure**, including headings, paragraphs, forms, images, and semantic elements. These examples show how content is organized and how browsers interpret markup. CSS demos build on this foundation by applying **styling, layout, and responsiveness**, helping you understand how design decisions affect user experience.

Each demo is intentionally kept **small and focused**. You are encouraged to:
- Inspect the HTML structure
- Modify CSS properties and observe changes
- Experiment with layouts using Flexbox and Grid

These demos form the foundation for modern frontend development and prepare you for advanced tools and frameworks such as **Bootstrap and React**, where the same core HTML and CSS principles are applied at a larger scale.

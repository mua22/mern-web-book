# Database Systems (CSC270) Labs

The topics include: the SELECT statement and filtering/sorting; single-row and group
functions; joins (inner, outer, self); subqueries and set operators; data manipulation
(DML) and table definition (DDL); views, indexes, and other schema objects; transaction
control and data control (GRANT/REVOKE); stored procedures, functions, and triggers; and
MongoDB — documents, CRUD, the aggregation pipeline, and replication/sharding.

Each lab below includes solved lab activities (with SQL/MongoDB code and solutions) and
graded lab tasks, run against the standard HR sample database (SQL labs) or an
HR-flavored document collection (MongoDB labs).

# DevOps

Everything here is tooling and workflow rather than a language or framework: getting
your machine ready for MERN-stack work, and the version control every project in this
course is built and submitted through. Start with environment setup if your machine
isn't ready yet, then Git and GitHub if version control is new to you, then the
submission workflow regardless of your Git experience — it covers this course's
specific repository structure and what counts as a valid, on-time submission.

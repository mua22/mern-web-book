# Environment &amp; Tooling

Before any of the course labs or tutorials below make sense, your machine needs the
same baseline every MERN-stack project assumes: a capable editor, Node.js and npm,
a way to auto-restart your server while you work, a MongoDB instance to connect to,
and Git for version control. This category is where that gets set up once, correctly,
so every later tutorial can just say "run `npm install`" and mean it.

If you already have all of this installed and working, you can safely skip ahead to
[HTML &amp; CSS Fundamentals](../html-css/index.md) or [Git &amp; Version Control](../git-version-control/index.md).

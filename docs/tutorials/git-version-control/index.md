# Git &amp; Version Control

Every project in this course — labs, assignments, and the team lab project — is
submitted through Git and GitHub, so this isn't optional background reading. Start
with the general tutorial if Git is new to you, then read the submission workflow
tutorial regardless of your Git experience: it covers this course's specific
repository structure and what counts as a valid, on-time submission.
